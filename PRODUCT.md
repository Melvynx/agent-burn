# Agent Burn

## Register

brand

## Users and purpose

Developers using Codex, Claude, Cursor and other coding agents. Help them understand subscription limits, token usage and API-equivalent spend through a native macOS app and an open-source CLI.

## Brand

Native, precise, approachable. The reference is the existing Agent Burn macOS application and Portly's downloadable Mac utility. Preserve the dark surfaces, warm flame identity and system typography already in the product.

## Design principles

- Show the working product with real application screenshots.
- Make downloading the Mac app and running the CLI easy to find.
- Separate API-equivalent value from actual subscription charges.
- Explain which data stays local and which provider requests happen.
- Keep source, release artifacts and update tooling available to contributors.

## Accessibility

Keyboard navigation, descriptive image alternatives, readable contrast and reduced motion support. Avoid dense marketing cards and decorative fake dashboards.
